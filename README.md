## What this is

Built for competitive Warzone players who want a cleaner mix — footsteps, comms, EQ — closer to what streamers run, without buying a preset pack.

The installer is a single .exe. It also sets up the secondary apps the stack needs:

- Voicemeeter — routing / virtual cables
- Equalizer APO — system-wide EQ
- Other small helpers those tools expect

No source code in this repo. Releases only.
